# 🚕 Uber Project Evaluation – Power BI Dashboard

This Power BI dashboard presents a synthetic analysis of Uber ride activity in Delhi. It uses a simulated dataset created using ChatGPT prompts to explore ride trends, trip performance, earnings, and other key metrics. The goal of this project is to demonstrate data visualization and business intelligence skills using Power BI.

---

## 📚 About the Dataset

The dataset used — `delhi Uber Ride.xlsx` — is a **synthetic dataset** generated using ChatGPT for the purpose of building an interactive Power BI dashboard.

### Key Fields:
- **Date/Time**: Timestamp of the ride
- **Pickup Location** and **Drop Location**
- **Trip Distance** and **Trip Duration**
- **Fare Amount**
- **Reason For Cancel the Ride**
- **Payment Method**

> ⚠️ This dataset is entirely artificial and does not reflect real-world Uber operations or rider behavior.

---

## 📊 Dashboard Features

- Booking Status Breakdown and frequent pick - up and drop location
- Total Booking and Distance Travelled By per Vehicle
- Earnings analysis by vehicle type and payment mode
- Reason for Cancel the ride by customer and Driver 
- Drive performance and customer Satisfaction level
